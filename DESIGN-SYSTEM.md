

# Re-Plan – Design System

This document contains the colors, fonts, and UI components used in our Re-Plan project. We have followed a dark theme with gold accents throughout the application.

## 1. Color Palette

| Color | Hex Code | Used For |
|---|---|---|
| Primary Gold | `#D4AF37` | Buttons and highlights |
| Secondary Gold | `#665323` | Borders and accents |
| Background | `#0B0B0D` | Page background |
| Card Background | `#171719` | Cards and sections |
| Input Background | `#252528` | Input boxes |
| Primary Text | `#F5F5F5` | Headings and main text |
| Secondary Text | `#9CA3AF` | Descriptions and smaller text |

## 2. Typography

**Font Family:** Geist Sans

| Text Type | Size | Style |
|---|---|---|
| Main Heading | 32px | Bold |
| Section Heading | 24px | Semi Bold |
| Card Heading | 20px | Semi Bold |
| Normal Text | 16px | Regular |
| Button Text | 16px | Semi Bold |
| Small Text | 14px | Regular |

## 3. UI Components

The following components are used in our application:

- **Navigation Bar:** Used to move between different pages. The active page is highlighted in gold.
- **Buttons:** Gold buttons are used for main actions, while secondary buttons have a dark background and gold border.
- **Cards:** Used to display subjects, schedules, and other information.
- **Input Fields:** Used to enter subject names and deadlines.
- **Dropdowns:** Used to select priority levels and other options.
- **Popups:** Display subject details and completion options when a schedule item is selected.
- **Sidebar:** Provides access to other sections of the application.
- **Badges:** Used to show priority levels and task status.
- **Loading State:** Shown while content is loading.
- **Empty State:** Shown when there are no subjects or schedules to display.
