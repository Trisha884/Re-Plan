Re-Plan – Plan Your Goals. Track Your Progress. Start Again.
Re-Plan is a goal-planning and progress-tracking web application designed to help people stay on track with their goals, even when plans don't go as expected.

Unlike traditional planners that focus only on completing tasks within deadlines, Re-Plan allows users to adjust missed deadlines and continue working towards their goals without losing their progress.

The idea is simple: Missing a deadline shouldn't mean giving up on a goal.

💡 The Problem
People often struggle to achieve their personal, academic, or professional goals because of unexpected situations, changing priorities, and unrealistic deadlines.

Traditional planning tools help organize tasks but often lack flexible ways to recover when users fall behind, which can lead to lost motivation and abandoned goals.

🎯 Our Solution
Re-Plan provides a flexible approach to goal management. Users can create goals, set deadlines and priorities, track completion, and reschedule delayed goals when needed.

Instead of starting over after missing a deadline, users can adjust their plans and continue from where they left off.

✨ Key Features
Goal Creation: Add goals with names and estimated durations.

Priority Management: Assign priorities to organize goals.

Visual Schedule: View goals through an interactive, winding-path-style roadmap.

Progress Tracking: Mark goals as completed and monitor progress.

Flexible Re-Planning: Reschedule missed deadlines and continue working towards the same goals.

Profile & Streak Board: View personal progress and activity.

🔄 How It Works
Create Your Goals – Add the goals you want to achieve.

Set Your Plan – Enter estimated durations, deadlines, and priorities.

Follow Your Schedule – View your goals in a visual roadmap.

Track Your Progress – Mark goals as completed.

Re-Plan When Needed – Adjust missed deadlines and continue towards your goals.

npm

Git

Installation
Clone the repository:

git clone https://github.com/Trisha884/Re-Plan.git
Navigate to the frontend folder:

cd Re-Plan/frontend
Install dependencies:

npm install
Start the development server:

npm run dev
Open http://localhost:3000 in your browser.

🎨 Design Approach
Re-Plan features a dark interface with charcoal backgrounds, warm gold accents, and light text. Its winding-path-style schedule represents goal achievement as a journey rather than a traditional task list.
